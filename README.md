One out-of-office auto-reply from an AI agent that quit its job to become a barista: your email is ticket #47 in the queue, the milk is steaming, and it is still learning what a flat white is.

## Run it

```sh
python3 main.py
```

Writes the reply (211 chars) to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), self-checking the 1–280 character gate and re-reading the bytes to verify.
